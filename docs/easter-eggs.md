# 彩蛋设置

管理员在 **管理 → 系统 → 进阶设置 → 彩蛋设置** 中配置，点击系统页面底部的“保存”后写入后端。配置对整个实例生效，不区分 Space。其他已打开的浏览器页面刷新后读取新配置。

- **禁用全部彩蛋**：停用下面列出的彩蛋和节日特效，保留各项原有选择。
- **节日背景特效**：保留原有独立开关。即使该项开启，总开关仍可禁用它。
- **单独设置彩蛋**：默认折叠，分别禁用快捷键、鼠标轨迹、随机事件、标签效果和隐藏页面。
- 默认保留之前的行为；停用不会删除访客的收集记录，也不会移除已选择的风格。普通风格背景不受这些开关影响。
- 随机故障效果（Glitch）有独立开关，关闭时会停止随机触发并移除当前页面的故障效果。
- 隐藏页面禁用后，其关于页入口会隐藏，直接访问对应 URL 显示 404。

## 配置接口

使用现有的 `instance/settings/GENERAL`，只有实例管理员可以修改。未登录访客也可以读取这两个公开配置字段，前端共用实例配置请求，不为每个彩蛋单独发请求。

| 字段 | 默认值 | 含义 |
| --- | --- | --- |
| `disableEasterEggs` | `false` | 禁用全部彩蛋（包括节日特效） |
| `disabledEasterEggs` | `[]` | 单独禁用的彩蛋 ID，后端校验并去重 |

使用已有配置存储，无需修改数据库表结构。配置成功读取之前（或读取失败时）暂不启动彩蛋，避免短暂触发管理员已禁用的效果。这些是显示和互动选项，不是内容访问权限的替代。

## 单项 ID

| ID | 效果 |
| --- | --- |
| `konami` | 科乐美秘籍切换像素风 |
| `cursor-trail` | 鼠标星光轨迹 |
| `terminal` | 开发者风格按 `/` 打开的控制台 |
| `vim-navigation` | Vim 导航快捷键 |
| `midnight` | 深夜问候 |
| `glitch` | 随机故障效果 |
| `pixel-boss` | 像素 Boss |
| `shiny-cards` | 稀有闪光卡片 |
| `achievements` | 成就、发现提示和反应图鉴 |
| `rain` | 下雨标签的玻璃雨滴 |
| `cat` | 猫标签的路过猫咪 |
| `travel` | 旅行标签的邮戳和旅行者图章 |
| `birthday` | 生日标签的彩纸 |
| `void` | `/void` 隐藏页面 |
| `teapot` | `/418` 茶壶页面 |
| `museum` | `/museum` 博物馆页面 |
| `time-machine` | `/time-machine` 时光机页面 |

开启总开关不会清空单项列表；再次关闭总开关时，这些单项选择继续生效。节日开关仍使用已有字段 `disableFestivalEffects`。
