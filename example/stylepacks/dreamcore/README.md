# 梦核 Dreamcore

似曾相识的梦：亮色配色是粉彩的午后云天，地平线上水天一线；暗色配色是紫色的银河。面板是半透明的乳白玻璃，边缘泛着珍珠般的彩虹光；站点标题发着光，旁边有闪烁的星星，下面一行小字写着“你以前来过这里。”。云里有一只若有若无、缓慢开合的眼睛，整页蒙着一层胶片颗粒。编辑器底下是一间泳池房的白色马赛克瓷砖。批量选择时，每篇文章旁边是一只闭着的眼睛，选中后睁开。

低功耗模式下颗粒、模糊和动画都会关掉；“减少动态效果”也会停掉动画。
