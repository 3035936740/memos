# 拟物化 Skeuomorphism

真实材质的风格：亮色配色下，文章是亚麻桌面上的一张张纸；暗色配色下，是红木桌上的缝线皮革夹。侧栏是皮革封面，顶栏是拉丝铝，站点标题是一块用螺丝固定的黄铜铭牌，按钮是上亮下暗的果冻按钮。置顶文章别着回形针，侧栏小组件用胶带贴在桌上，编辑器是红色装订的黄色便笺，每日一问是一张便利贴，标签云是牛皮纸行李牌。

亚麻、皮革和纸张纹理是灰度的，用正片叠底混进主题颜色，所以换任何配色都协调。
