# 隔离的演示模式

现有演示地址是 <https://memos.bing.tomato-universe.tech/>。这个地址本身不意味着允许删除站点数据：普通部署继续使用默认的生产模式。

只有显式设置 `MEMOS_DEMO=true` 才会在启动时和之后每隔 24 小时重置演示数据库。必须使用单独的数据卷，不能挂载生产数据目录或生产数据库 DSN。演示模式只支持 SQLite。

```bash
docker compose -f deploy/docker-compose.demo.yml up -d
```

该示例绑定本机 5231 端口，由反向代理映射到单独的测试域名。确认站点数据可以全部丢弃后，再决定是否把既有演示域名指向它。

演示数据包括三个空间、风格和标签效果说明、系列文章、投票，以及一段本地生成的八秒循环音乐。管理员账号、实例设置和 SSO 配置禁止通过演示 API 修改；附件和头像限制为 1 MiB。普通访客可注册自己的账号体验编辑，数据在下次重置时清除。部署提供的访问策略和身份提供商配置保留，访客账号 ID 不会循环复用。

重置在一个数据库事务里完成；附件存储清理失败时留在重试队列。任务随服务器 context 取消，重置失败记录到服务器日志。不要在演示环境存放私人信息。

发布流程需要先推送代码，再由 Actions 构建 canary；正式发布使用 `v1.x.y` 标签。此说明不会自动发布镜像、创建 Release 或修改线上站点。
