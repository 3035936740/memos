# 本次后端接入与验证

## 已接入

- 空间切换保留 `/space/<UID>`，设置别名后使用 `/space/<别名>`。发现使用空间入口，主页、附件和分类等使用其下的子路径；普通导航保留当前空间，只有显式切回主站时才恢复主站地址。直接打开、刷新和复制链接会进入对应空间页面。
- 设置内层面板、表格、弹窗和菜单使用共享风格边框；手绘风格只让轮廓抖动，正文不参与滤镜。滤镜定义放在应用根部，设置页面和门户菜单也能使用。
- 管理员全站 ZIP 导出：Markdown 原文、YAML 元数据、本地/S3 附件选项、缺失附件报告、可选 SQLite 敏感快照、取消和单任务锁。文章和附件查询分页，服务端不把整个 ZIP 放进内存。
- 回收站：默认 30 天、删除撤销、个人/管理员列表、恢复、彻底删除、清空和每小时过期清理。删除评论按相同规则处理；软删除在三个驱动的默认查询中隐藏，附件直链也返回不存在。物理存储删除失败保留重试记录。
- 私有历史版本：正文或标题变化时同事务保存旧版，同一编辑者十分钟内合并，默认保留 20 条。列表只读取摘要；恢复走正常更新逻辑；支持单条删除和清空。普通读者不能读取历史。
- 大量空间：SQL 内完成可见性过滤、排序及分页；支持 JOINED、批量读取、总数和有上限的抽样。目录头像使用受权限控制的短地址。文章数和活跃时间只统计可公开列出的正文，管理员也使用同样口径。
- 独立 Plus 迁移台账，三驱动迁移与最新安装结构同步。`deleted_ts` 使用 Unix 微秒，精确区分独立删除批次。SQLite 升级前快照失败会停止升级，保留最近三份备份。
- 安装向导完成状态、页脚开关保存到后端。独立发布版本用于 CLI 和实例信息，原版兼容版本继续用于迁移。
- GHCR canary、正式标签、多架构镜像和 Release 二进制流程已改为本分支；未向远端推送或实际发布。
- 隔离 demo 模式：启动和每隔 24 小时重置、三个空间及示例文章/投票/本地音乐、管理员与系统配置保护、1 MiB 上传限制。普通生产部署不会自动开启重置。

## 本机验证

- 前端 TypeScript 检查及 `pnpm release` 通过，未运行额外前端单元测试。
- SQLite 下完整 Go 回归和服务端 race 检查通过；新增测试包含两万个空间的分页/排序/抽样、历史权限与恢复、备份解压和快照、过期清理重试、头像及附件可见性、升级与重复重置。
- `buf generate`、`buf lint` 及工作流/Compose YAML 解析通过。
- Go 静态规则检查为 0 问题。Windows 未修改文件的 CRLF 换行会触发默认 goimports 检查；验证时将该格式化检查分开执行，改动 Go 文件单独格式化检查无差异。
- 最终构建在独立空库上健康检查返回 HTTP 200，实例版本同时显示 Plus 与原版版本。Windows 空库工作集约 38 MiB，私有内存约 63 MiB；该数字不是 Linux 容器最低配置验收。
